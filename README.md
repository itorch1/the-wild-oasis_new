# The Wild Oasis

A modern internal app for hotel management: cabins, bookings etc.
Uses Supabase service for backend DB management, storage and authentication.
Includes beautiful charts using Recharts library for statistics display.

Tutorial real-world project featuring CRUD, as well as many libraries used in modern development.

### Libraries used:

- React Router
- Tanstack Query (React Query)
- Styled Components
- Supabase-JS
- React Hook Form
- React Hot Toast
- React Error Boundary
- Recharts
- Date-Fns
- React Icons
